O que são skills e como usar

Uma skill é um manual que o Claude lê quando precisa fazer uma tarefa específica. Instalar é o primeiro passo; o segundo é saber pedir. Esta página explica os dois, sem termos técnicos.

O que é uma skill

Pense numa receita. O Claude sabe cozinhar em geral, mas uma receita de quem já fez o prato mil vezes deixa o resultado mais certeiro. A skill é essa receita: instruções escritas por alguém que já resolveu aquele problema, como montar um PDF, revisar código, criar uma apresentação ou escrever um texto no tom certo.

Na prática, é uma pasta com um arquivo chamado SKILL.md. Algumas trazem também scripts (programas que o Claude pode rodar) e modelos de arquivos. Tudo é texto e arquivos comuns, nada é instalado "por baixo dos panos".

Sem a skill, o Claude responde com o que já sabe. Com ela, ele segue o método de quem é especialista naquele assunto, e o resultado fica mais parecido de uma vez para outra.

minha-skill/ ├─ SKILL.md o manual: nome, descrição e passo a passo ├─ scripts/ opcional: programas que a skill usa └─ modelos/ opcional: arquivos de apoio
--- name: minha-skill description: Cria relatórios em PDF a partir de planilhas. Use quando pedirem um PDF. --- # Passo a passo 1. Leia a planilha enviada. 2. Monte o PDF com o modelo da pasta. 3. Confira os números antes de entregar.

O topo do arquivo (entre os ---) tem o nome e uma descrição curta. O resto é o passo a passo.

Como o Claude usa uma skill

Ele não lê todas as skills a cada conversa, isso seria lento e caro. Funciona em três etapas:

1. Ele conhece o nome e a descrição

Ao abrir, o Claude vê só o nome e a descrição curta de cada skill instalada. É como ler a lista de títulos de uma estante.

2. Você pede a tarefa

Se você cita a skill, ele a escolhe na hora. Se não citar, ele pode escolher sozinho quando a descrição combina com o pedido, mas isso não é garantido.

3. Ele abre o manual e segue

Só então lê o SKILL.md inteiro (e os arquivos de apoio, se houver) e executa a tarefa seguindo aquelas instruções.

Importante: peça pelo nome

Por causa dessa etapa 2, uma skill instalada fica guardada, mas não é usada em toda conversa. Se você só pedir "faça um PDF", o Claude pode resolver do jeito dele e nem olhar a skill. O jeito garantido é dizer o nome na hora de pedir:

Use a skill nome-da-skill para fazer isso

Escreva do seu jeito. Só o nome da skill precisa estar certo.

/nome-da-skill

Atalho do Claude Code: digite / e o nome da skill.

O nome certo aparece no painel de cada skill aqui no catálogo e na aba Instaladas, com a frase pronta para copiar.

Exemplo de conversa

Sem citar a skill
Faça um relatório em PDF com as vendas deste mês.

O Claude faz do jeito dele. Pode ficar bom, mas o formato muda a cada vez e a skill é ignorada.

Citando a skill
Use a skill pdf para fazer um relatório com as vendas deste mês.

O Claude abre o manual da skill e segue os passos dela, com o formato e as conferências que o autor definiu.

Onde as skills ficam

Globais

As que este catálogo instala. Ficam em ~/.claude/skills e valem em todos os seus projetos. Boas para o que você usa sempre.

Só de um projeto

Ficam em .claude/skills, dentro da pasta do projeto, e valem só ali. Boas para regras específicas de um trabalho ou de uma equipe.

Desinstalar apaga a pasta da skill do seu computador. Você pode instalar de novo quando quiser, e o seu perfil continua mostrando as favoritas.

Cuidados

Uma skill pode incluir scripts que o Claude executa no seu computador, então vale o mesmo cuidado de baixar qualquer programa. Antes de instalar:

  • Abra Ler o SKILL.md no painel da skill e leia o que ela manda o Claude fazer.
  • Olhe as estrelas e a data da última atualização do repositório.
  • Prefira autores e organizações em quem você confia.

Perguntas rápidas

Preciso saber programar?
Não. Você instala com um clique e pede em português normal.
Instalei, mas o Claude não usou.
Cite o nome da skill no pedido, como no quadro laranja acima. Se ela nem aparece na lista do Claude, reinicie o Claude Code.
Dá para usar mais de uma skill?
Dá. Cite as duas no mesmo pedido: Use as skills a e b para…
Deixa o Claude mais lento ou gasta mais?
Pouco. Só o nome e a descrição entram na conversa; o manual inteiro é lido quando a skill é usada.
Quanto custa?
As skills são grátis. O Claude Code segue o seu plano de sempre.
Posso criar a minha?
Pode: crie uma pasta com um SKILL.md em ~/.claude/skills. Ela aparece na aba Instaladas.
